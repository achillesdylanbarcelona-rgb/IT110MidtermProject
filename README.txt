Instructions to Run the App:
1. Extract the project files into a single folder.
2. Ensure portfolio.html, rqgenerator.html, styles.css, and script.js are located in the same directory.
3. Open index.html in any modern web browser (Chrome, Firefox, Edge, etc.) to view the Group Portfolio.
4. Click the "Launch Quote Generator" button in the portfolio to navigate to the main application (app.html).
5. An active internet connection is required to fetch new quotes from the external API.
